# Forkeazando

Jogo narrativo interativo em Java, desenvolvido para a disciplina EXA863 (MI - Programação) da Engenharia de Computação da UEFS.

Uma sátira sobre a trajetória de um estudante de Engenharia de Computação, do ingresso como calouro até a entrada na carreira profissional, onde escolhas ao longo do caminho, 
participar de iniciação científica, monitoria, ou seguir por conta própria, determinam o rumo profissional do protagonista.

Projeto Maven. Na raiz do repositório:

```bash
mvn compile
java -cp target/classes br.uefs.forkeazando.Main
```
